# CareerTrack AI

## Track Skills. Stay Consistent. Become Placement Ready.

Build a complete, modern, responsive web application called **CareerTrack AI**.

CareerTrack AI is a role-based placement preparation and learning management platform for students. It helps students choose their target career role, follow a structured learning roadmap, organize their learning into checkable milestones, set daily goals, maintain learning streaks, receive notifications, monitor progress through analytics, and evaluate their overall placement readiness.

The platform should feel like a combination of a **career roadmap + learning tracker + habit tracker + placement readiness dashboard**.

---

# 1. PROJECT OBJECTIVE

The primary objective of CareerTrack AI is to provide students with a single platform to systematically prepare for placements instead of using scattered resources such as YouTube, coding platforms, spreadsheets, notes and to-do applications.

The system should:

* Provide role-specific career roadmaps.
* Break each role into specific skills, technologies and learning milestones.
* Allow students to mark completed learning topics using checkboxes.
* Organize learning into structured sections and sub-sections.
* Allow students to create and complete daily learning goals.
* Track daily learning consistency.
* Maintain a learning streak similar to habit-based learning applications.
* Send notifications reminding students about unfinished daily goals.
* Congratulate students when daily goals are completed.
* Track overall skill and roadmap completion.
* Provide study analytics.
* Calculate a placement readiness score.
* Show students what they have completed and what they still need to learn.
* Give students a clear and organized path toward their selected placement role.

# 14. LEARNING STREAK SYSTEM

Implement a learning streak system inspired by habit-based learning applications such as Duolingo.

Show prominently:

🔥 Current Streak: 12 Days

Also show:

* Current streak
* Longest streak
* Total active learning days
* Today's goal status
* Weekly consistency
* Monthly consistency

Rules:

* If the student completes their required daily goal, the day counts toward the streak.
* If they do not complete the daily goal, the streak should normally reset.
* Avoid double-counting multiple completions on the same day.
* Store the last completed learning date.
* Calculate the streak automatically.
* Display encouraging messages.

Examples:

"🔥 5 day streak! Keep going!"

"🔥 You're on a 12 day learning streak!"

"Don't break your streak today!"

"🎉 Daily goal completed! Great work!"

# 41. FINAL PRODUCT VISION

CareerTrack AI should answer five questions for every student:

1. What role am I preparing for?
2. What should I learn next?
3. What have I already completed?
4. Am I being consistent?
5. How ready am I for placements?

The application should transform placement preparation from an unorganized collection of resources into a structured, measurable and motivating learning journey.

The central experience should be:

CHOOSE ROLE
→ FOLLOW ROADMAP
→ CHECK OFF LEARNING
→ COMPLETE DAILY GOALS
→ BUILD STREAK
→ TRACK PROGRESS
→ ANALYZE PERFORMANCE
→ IMPROVE WEAK AREAS
→ MEASURE READINESS
→ PREPARE FOR PLACEMENTS

Build the application as a **fully functional product**, not merely a UI prototype.

All major buttons, checkboxes, progress calculations, authentication, database operations, notifications, streak calculations, analytics and roadmap interactions should work end-to-end.
